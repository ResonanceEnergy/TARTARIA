## 💡 PRO TIPS

1. **Pink Materials Are Normal**  
   We haven't applied textures yet — that's Phase 3. Geometry is what matters now.

2. **Console Panel = Your Friend**  
   Window → General → Console (Ctrl+Shift+C). Check for green ✓ checkmark messages.

3. **Scene View vs Game View**  
   Scene View = editor camera (can fly around). Game View = player camera (WASD controls).

4. **F Key for Focus**  
   Select any wall in Hierarchy, press F in Scene View to zoom camera to it.

5. **Exit Play Mode Before Editing**  
   Press Play button again (turns blue when active). Changes made in Play Mode don't save!
