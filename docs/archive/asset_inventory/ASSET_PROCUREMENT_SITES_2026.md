## 📦 DIRECT DOWNLOAD WORKFLOW

### **Step 1: Unity Asset Store Assets (15 minutes)**
1. Open Unity Editor
2. Window → Asset Store
3. Search for packages above
4. Click "Add to My Assets" (free, no payment)
5. Window → Package Manager → My Assets
6. Download + Import each package
7. Wait for import to complete (progress bar bottom-right)

### **Step 2: Freesound.org Audio (20 minutes)**
1. Create free account at Freesound.org
2. Search for asset names from list above
3. Download WAV format (highest quality)
4. Save to `Assets/_Project/Audio/SFX/` folder
5. Create `AUDIO_CREDITS.txt` in project root with attribution

### **Step 3: Mixamo Characters (10 minutes)**
1. Create free Adobe account at mixamo.com
2. Browse Characters → Download "Peasant Man" (FBX for Unity, T-pose)
3. Browse Animations → Download "Talking", "Idle", "Waving" (FBX, In Place)
4. Import FBX files to `Assets/_Project/Models/Characters/`
5. Set rig to "Humanoid" in Unity Inspector

### **Step 4: Kenney Assets (10 minutes)**
1. Visit https://kenney.nl/assets
2. Download "UI Pack", "Props Pack", "Puzzle Pack"
3. Extract ZIP files
4. Drag folders into `Assets/_Project/Vendor/Kenney/`
5. Create prefabs from models

### **Step 5: Poly Haven Textures (15 minutes)**
1. Visit https://polyhaven.com/textures
2. Search "stone wall", "wood planks", "metal rust"
3. Download 2K resolution (Color + Normal + Roughness + AO)
4. Import to `Assets/_Project/Textures/PBR/`
5. Create URP/Lit materials in Unity

**Total Time: ~70 minutes for all essential assets**

## ⚠️ IMPORTANT NOTES

### **Licenses Summary**
- **CC0 (Public Domain):** Use freely, no attribution required (Kenney, many Freesound files)
- **CC BY 4.0:** Use freely, attribution required (most Freesound, some Mixamo)
- **Unity Asset Store EULA:** Free for commercial use in Unity projects
- **Adobe Mixamo:** Free for commercial use, Adobe account required

### **Attribution Template** (for CC BY assets)
Create `CREDITS.md` in project root:
```
# TARTARIA - Third-Party Asset Credits

## Audio
- "Power Up 01" by LittleRobotSoundFactory (Freesound.org) - CC BY 4.0
- "Secret Found" by Leszek_Szary (Freesound.org) - CC BY 4.0

## 3D Models
- Character models from Mixamo (mixamo.com) - Free with Adobe account

## Textures
- PBR textures from Poly Haven (polyhaven.com) - CC0 Public Domain

## UI
- Kenney.nl UI Pack (kenney.nl) - CC0 Public Domain
```

### **Import Best Practices**
1. **Audio:** Import as WAV, set compression format to "Vorbis" (smaller file size)
2. **3D Models:** Import FBX, set scale to 1.0, rig to "Generic" or "Humanoid"
3. **Textures:** Import as "Default" for albedo, "Normal Map" for normals
4. **VFX:** Import Unity packages via Package Manager (maintains references)

### **Storage Recommendations**
- Total estimated download size: ~500 MB - 1 GB
- Unity project size after import: ~2-3 GB
- Keep original ZIP files in `Downloads/TARTARIA_Assets/` for backup
