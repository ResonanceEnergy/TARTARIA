# TARTARIA — Beta v0.9

**An open-world adventure through the resonant frequencies of a forgotten civilization.**

---

## 🚀 Quick Start

1. **Extract the ZIP** to a folder of your choice (e.g., `C:\Games\TARTARIA\`)
2. **Run `TARTARIA.exe`** to start the game
3. **First launch:** Allow Windows Firewall if prompted (for future online features)
4. **Configure graphics:** Use the launcher to set your resolution and quality preset
5. **Start playing:** Select "New Game" from the main menu

**Pro tip:** If you encounter performance issues, lower the "Shadow Quality" setting first — it has the biggest impact.

## 💾 Save File Location

Your game saves are stored at:
```
%APPDATA%\Tartaria\Saves\
```

Full path example:
```
C:\Users\YourName\AppData\Roaming\Tartaria\Saves\
```

**Backup your saves!** Beta saves may not be compatible with future versions.

## ⚙️ System Requirements

### Minimum
- Windows 10 64-bit (1909+)
- Intel Core i5-8400 / AMD Ryzen 5 2600
- GTX 1060 6GB / RX 580 8GB (DX12 required)
- 12 GB RAM
- 5 GB storage

### Recommended
- Windows 11 64-bit
- Intel Core i7-10700 / AMD Ryzen 7 3700X
- RTX 3060 / RX 6700 XT
- 16 GB RAM
- 8 GB storage (SSD recommended)

## 🎮 Controls

### Keyboard & Mouse
- **WASD** — Movement
- **Space** — Jump
- **E** — Interact / Scan
- **Q** — Resonance Scanner
- **Tab** — Inventory
- **J** — Quest Log
- **M** — Map
- **Esc** — Pause Menu

### Gamepad (Xbox Layout)
- **Left Stick** — Movement
- **Right Stick** — Camera
- **A** — Jump
- **B** — Dodge
- **X** — Interact / Scan
- **Y** — Scanner

- **Menu** — Pause

## 🐛 Known Issues

This is a **BETA BUILD**. Expect some rough edges:

### High Priority
- Giant Mode scaling may jitter on low-end hardware
- Companion pathfinding can get stuck in dense forests
- Beta saves may not transfer to v1.0

### Medium Priority
- Some late-game audio uses placeholder tones
- First load of each Moon may cause brief hitches
- Quest log doesn't separate completed vs active quests

**Full details:** See `BETA_RELEASE_NOTES.md`
