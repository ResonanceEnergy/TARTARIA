#### 1. SaveData Migration System (6h)
**Problem:** SaveData version field exists but no actual migration logic. Schema changes will corrupt saves.

**Solution:**
```csharp
public class SaveDataMigrator
{
    public static SaveData Migrate(SaveData data)
    {
        while (data.version < SaveData.CurrentVersion)
        {
            data = MigrateNext(data);
        }
        return data;
    }

    static SaveData MigrateNext(SaveData data)
    {
        switch (data.version)
        {
            case 17: return MigrateV17ToV18(data);
            case 18: return MigrateV18ToV19(data);
            // Add new migrations here
            default: return data;
        }
    }

    static SaveData MigrateV17ToV18(SaveData data)
    {
        // Add new fields with defaults
        data.player.equipmentSlots = new EquipmentSaveData();
        data.version = 18;
        return data;
    }
}
```

**Deliverables:**
- `SaveDataMigrator.cs` (150 lines)
- Unit tests for v17→v18 migration
- Integration with SaveManager.Load()

### Priority 2: Nice to Have (8 hours)

#### 5. Data Denormalization Cache (4h)
**Problem:** Complex queries run O(n) every time (e.g., `GetQuestsByMoon()`).

**Solution:** Build lookup tables on first access, cache for O(1) queries.

**Example:**
```csharp
public class QuestDatabase : ScriptableObject
{
    [SerializeField] List<QuestData> quests;
    
    // Lazy-initialized caches
    Dictionary<int, List<QuestData>> _questsByMoon;
    Dictionary<QuestCategory, List<QuestData>> _questsByCategory;
    
    public List<QuestData> GetQuestsByMoon(int moonId)
    {
        if (_questsByMoon == null) BuildMoonCache();
        return _questsByMoon.TryGetValue(moonId, out var list) ? list : new();
    }
    
    void BuildMoonCache()
    {
        _questsByMoon = quests
            .GroupBy(q => q.moonId)
            .ToDictionary(g => g.Key, g => g.ToList());
    }
}
```

**Impact:** Reduces query time from 5ms → 0.1ms (50x faster) for 200+ quests

**Deliverables:**
- Cache system in QuestDatabase.cs
- Cache system in ItemDatabase.cs (category/rarity filters)
- Benchmark tests (verify 50x speedup)
