## Download & Import Instructions

### Unity Asset Store Assets
1. Open Unity Hub → Sign in to Unity account
2. Visit asset URL in browser → Click "Add to My Assets"
3. Open Unity Editor → Window → Package Manager
4. Switch to "My Assets" tab → Search for asset
5. Click "Download" → "Import" → Select components needed

### Freesound.org Audio
1. Visit sound URL → Click "Download" button (requires free account)
2. Choose format: WAV (highest quality) or OGG/MP3 (compressed)
3. In Unity: Drag audio file to `Assets/Audio/` folder
4. Select audio in Project → Inspector:
   - Set "Load Type": Streaming (for loops) or Compressed In Memory (for SFX)
   - Check "Preload Audio Data" for instant playback sounds
   - Set "Quality": 100% for notifications, 70% for ambience

### Kenney.nl Assets
1. Visit asset pack URL → Click "Download" button (no account needed)
2. Extract ZIP file to temporary folder
3. In Unity: Import desired files to appropriate folders
   - UI PNG → `Assets/UI/Sprites/`
   - Audio → `Assets/Audio/`
4. For UI sprites: Set Texture Type to "Sprite (2D and UI)" in Inspector

### OpenGameArt.org
1. Visit asset URL → Click "Download" link
2. Check license requirements (some require attribution)
3. Import to Unity as with other assets
4. If attribution required: Add credit to `CREDITS.md` in project root

## Asset Customization Notes

### Quest Marker VFX Customization
- **Color Changes:** Modify Particle System → Color over Lifetime gradient
- **Gold Marker:** RGB (255, 215, 0) or HSV (51°, 100%, 100%)
- **Green Marker:** RGB (0, 255, 128) or HSV (150°, 100%, 100%)
- **Blue Marker:** RGB (0, 191, 255) or HSV (195°, 100%, 100%)
- **Scale:** Adjust "Start Size" in particle system (recommend 2-5 units for visibility)
- **Height:** Extend "Start Lifetime" for taller beams

### Audio Layering Technique
For rarity progression (Common → Rare → Epic):
1. **Common:** Single chime, 0.2-0.5s duration, mid-high pitch
2. **Rare:** Layer 2 sounds (chime + whoosh), 0.5-1.0s, mid pitch, add reverb
3. **Epic:** Layer 3+ sounds (chord + sparkle + whoosh), 1.0-2.0s, fuller frequency range, heavy reverb

Unity AudioMixer recommended for processing:
- Create 3 mixer groups: "Collectible_Common", "Collectible_Rare", "Collectible_Epic"
- Rare: Add reverb effect (Room Size: 0.3, Decay: 1.0s)
- Epic: Add reverb (Room Size: 0.5, Decay: 1.5s) + pitch shift (-2 semitones for depth)

### Weather Audio Loops
Ensure seamless looping:
1. Import with "Loop" checkbox enabled in Inspector
2. Set "Load Type" to "Streaming" (memory efficient for long loops)
3. Adjust "Gapless Loop" settings if clicks/pops occur at loop point
4. Consider crossfading between weather states (use Audio Source "FadeOut/FadeIn" or DOTween)

## Troubleshooting Common Issues

### "Missing Shader" Warnings
- **Cause:** Asset built for different render pipeline (Built-in vs URP vs HDRP)
- **Fix:** Upgrade materials via Edit → Render Pipeline → Upgrade Materials
- **Prevention:** Check asset description for pipeline compatibility before download

### "Audio Clip Could Not Be Loaded"
- **Cause:** Wrong import settings or corrupted file
- **Fix:** Reimport audio file, check format (prefer WAV/OGG over MP3)
- **Note:** Some Freesound MP3s have incorrect headers - convert to WAV in Audacity

### Particle Effects Not Visible
- **Cause:** Shader compatibility, layer culling, or scale issues
- **Fix:** Check Camera culling mask includes VFX layer
- **Debug:** Select effect in Hierarchy → Scene view → Toggle "Effects" button in Scene toolbar

### UI Icons Blurry/Pixelated
- **Cause:** Incorrect import settings for sprites
- **Fix:** Select texture → Inspector:
  - Texture Type: "Sprite (2D and UI)"
  - Filter Mode: "Bilinear" (or "Point" for pixel art)
  - Compression: "None" for high quality
  - Max Size: 2048 or higher for large icons
