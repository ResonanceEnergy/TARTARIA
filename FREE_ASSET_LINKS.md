## 🎯 PROTIP: Batch Download Script

Save this as `download_freesound.ps1` to automate organization:

```powershell
# Create folder structure
$audioRoot = "Assets\_Project\Audio"
$folders = @(
    "$audioRoot\Music",
    "$audioRoot\SFX\Player\Movement",
    "$audioRoot\SFX\Player\Combat",
    "$audioRoot\SFX\Enemies",
    "$audioRoot\SFX\Environment"
)

foreach ($folder in $folders) {
    if (-not (Test-Path $folder)) {
        New-Item -ItemType Directory -Path $folder -Force
        Write-Host "Created: $folder"
    }
}

Write-Host ""
Write-Host "✅ Folder structure created!" -ForegroundColor Green
Write-Host "Now download files from Freesound and place in appropriate folders."
```
